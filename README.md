# minoise

Real-time voice denoiser VST3 for Windows x64, by Mintaria.

**[Download the latest release](https://github.com/ysuhao/minoise/releases/latest)**

| | |
|---|---|
| Format | VST3, Windows x64 |
| Host sample rates tested | 16, 44.1 and 48 kHz |
| Reported latency | 37.90 ms at 48 kHz |
| Controls | Voice and Ambience dials, lite mode, bypass |

## Install

Extract the whole ZIP, run `install.bat`, then rescan VST3 plugins in your host. To check a download without installing, run `install.bat --verify-only`.

## 설치

ZIP 전체를 압축 해제하고 `install.bat`을 실행한 뒤 호스트에서 VST3 플러그인을 다시 스캔하세요.

## 安装

先完整解压 ZIP，再运行 `install.bat`，然后在宿主里重新扫描 VST3 插件。运行 `install.bat --verify-only` 可以只校验下载内容、不安装。
